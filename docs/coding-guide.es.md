# Guía de codificación sustantiva

## Unidad de análisis

Cada fila representa una referencia de Zotero. La llave primaria es `Key`. No la modifiques: permite actualizar metadatos sin perder la codificación interpretativa.

## Secuencia recomendada

1. Define la pregunta de revisión antes de crear categorías.
2. Codifica exposición, recursos, mecanismo y resultado por separado.
3. Registra el diseño y la temporalidad.
4. Evalúa el estatus empírico del mecanismo.
5. Asigna una función potencial dentro del manuscrito.
6. Construye núcleos amplios solo después de revisar los campos anteriores.

## Núcleo sustantivo

`Cluster` sirve para visualizar la estructura del corpus. Debe ser relativamente pequeño y mutuamente excluyente solo para fines gráficos. Un artículo puede participar de más de una conversación teórica; la clasificación representa su contribución dominante para la pregunta de revisión.

## Mecanismos

Evita definir un mecanismo como el nombre de una variable intermedia. Un mecanismo debe describir actores, recursos, restricciones o procesos que hagan inteligible el paso entre exposición y resultado.

## Nivel de afirmación

Usa `Mechanism observation` para distinguir:

- `Mentioned`
- `Associated`
- `Modelled`
- `Identified`

Estas categorías no son una escala automática de calidad. Un artículo descriptivo puede ser excelente sin identificar un mecanismo causal.

## Relevancia

- `Central`: necesario para el argumento principal.
- `Complementary`: aporta contexto, contraste o un mecanismo lateral.
- `Peripheral`: su inclusión debe justificarse o revisarse.

## Control de calidad

Revisa prioritariamente:

- registros sin resumen;
- categorías inferidas solo desde títulos;
- mecanismos modelados como mediaciones observacionales;
- comparaciones entre contextos institucionales muy distintos;
- campos pegados literalmente desde material protegido.

Parafrasea hallazgos y limitaciones con tus propias palabras.
