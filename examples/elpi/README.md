# ELPI example

The root application loads the ELPI demonstration from:

- `data/zotero-example.csv`: ten bibliographic records with short paraphrased descriptions.
- `data/coding-example.csv`: substantive coding used to build the conceptual view.
- `data/codebook.csv`: definitions and recommended coding rules.

The example illustrates a review about economic conditions, household resources, family processes, and child development. Its categories are specific to that question and should not be treated as a universal taxonomy.
