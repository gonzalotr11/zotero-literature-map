# Contributing

Thank you for considering a contribution.

1. Open an issue describing the problem or proposed change.
2. Keep new coding fields optional and document their methodological meaning.
3. Do not commit copyrighted PDFs, full publisher abstracts, private notes, or local attachment paths.
4. Test both descriptive mode and substantive mode.
5. Preserve local-only file processing unless a future network feature is explicit and opt-in.
